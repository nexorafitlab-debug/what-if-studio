- **school hallway** (interiorWarm): key light = windows. Window/view = corridor view, lockers. Signature props: lockers, water fountain, doorway. Layers: sky → far (building) → mid (lockers) → floor → foreground (lockers, decor).
- **cafeteria** (interiorWarm): key light = windows. Window/view = food service counter, outdoor view. Signature props: counter, trays, vending machines. Layers: sky → far (building) → mid (wall panels) → floor → foreground (counter, trays, blurred foreground).
- **exam hall** (interiorCool): key light = fluorescent strips. Window/view = none (blanks walls). Signature props: desks, chairs, pencil sharpener. Layers: void → grid → desks → floor → foreground.
- **busy street** (golden hour): key light = sun. Window/view = facades with warm lit windows, passing skyline. Signature props: lamp posts, trees, benches, passing cars. Layers: sky → far (skyline) → mid (building facades) → floor → foreground (lamp posts, street trees).
- **rooftop** (dusk): key light = sun low, rim from building edge. Window/view = city skyline, sunset. Signature props: low wall, wind, distant skyline. Layers: sky → far (skyline) → mid (building edge) → floor → foreground (wall, wind).
- **black screen** (void): key light = none (flat even lighting). Window/view = none. Signature props: none. Void for the final question. Layers: void → text.

## Motifs
- **Countdown numbers** as BIG gold on-screen ticking numbers (10-9-8, 5-4-3, 2-1). Gold = the 10-second vision device.
- **Kian's blue hoodie** — the only cool signature colour in otherwise warm sets.
- **Freeze moment** on rooftop: time stops, particles hang, only Kian moves (or the girl catches the phone).
- **On-screen text**: gold "10 SECONDS" device label, the hook line on the black screen.
- **Face close-ups** on beat: Kian's reactions to what he sees.
